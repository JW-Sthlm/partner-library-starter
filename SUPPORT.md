# Support

This repository is a personal experiment by Johan Wallquist, shared as a starter template for anyone building a small partner library or knowledge site on top of VitePress and Azure Static Web Apps.

## What this repo is

A scaffold to learn from and fork. Working, tested, but minimal.

## What this repo is not

- Not a Microsoft product.
- Not an officially endorsed Microsoft template, reference architecture, or sample.
- Not under any SLA.
- Not actively maintained on a schedule.

## Getting help

- **For your fork:** you own it. Once you create a repo from this template, your copy is independent. Content, Azure resources, secrets, access control, costs, and security are all yours.
- **For Azure Static Web Apps:** see the [official Azure SWA docs](https://learn.microsoft.com/azure/static-web-apps/).
- **For VitePress:** see [vitepress.dev](https://vitepress.dev/).
- **For Application Insights:** see [the Azure Monitor docs](https://learn.microsoft.com/azure/azure-monitor/).

## Issues and PRs

You're welcome to open issues or PRs. They'll be reviewed when time permits, on a best-effort basis. No commitment, no schedule.

## Security

For suspected security issues in this template's source, see [SECURITY.md](SECURITY.md). For security issues in your own deployed copy, that's your responsibility.
